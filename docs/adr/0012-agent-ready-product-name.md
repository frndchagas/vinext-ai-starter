# ADR 0012: agent-ready product name

Status: accepted.
Implementation: pending.

The project will use **Vinext Laravel Starter** as its public name and `vinext-laravel-starter` in repository and package identifiers. “AI” was removed because the running application deliberately has no AI provider or AI behavior; the differentiator is a Laravel and Vinext foundation designed to be developed safely with coding agents. The renamed package will restart at v1.0.0 because the original package has no consumers. The original release and tags will be removed from the source and generated distribution, and the existing Packagist package will be retired before the adoption campaign begins.
